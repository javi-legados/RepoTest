# Contract: History Events

| Source | Event | Recorded content |
|---|---|---|
| Spec 4/6 | Created, Submitted | Person, date |
| Spec 6/8 | Review released or returned | Reviewer, outcome, comments |
| Spec 7 | Approved, Rejected, Skipped, Hold, Resume | Approver, level, comments |
| Spec 3 | Reassigned | Previous/new approver, reason |
| Specs 4/5 (after submission) | Field Changed, Attachment Added/Removed | Field, old/new, file name |
| Spec 10 | Data Corrected, Completed | Field, old/new, person |
| Spec 9 | Notification Outcome | Result and reason |
| Specs 1/2/3 | Role and approver assignment changes | Old/new value, person → Administrative Audit |

Rules: draft-time edits are not recorded; entries cannot be edited or deleted; name snapshot kept; visible on screen only to users who can open the request (administrative audit: administrators only); no export.
