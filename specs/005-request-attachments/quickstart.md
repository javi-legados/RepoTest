# Quickstart: Validating Attachments

1. Upload several valid files at once → all listed with name, size, uploader, date.
2. Upload one over 25 MB, one .exe, and a duplicate name together with valid files → only the invalid ones are rejected, each with a reason.
3. Try a 21st file → rejected.
4. Save and reopen the Draft → attachments intact.
5. Remove one in Draft → gone; submit and try again as Creator → blocked.
6. As approver and read-only user: view and download work; add/remove unavailable and denied by API.
7. As administrator: upload during review; uploader shows the administrator.
8. Delete a Draft → attachments removed.
9. Return a request for correction → Creator can add/remove again.
