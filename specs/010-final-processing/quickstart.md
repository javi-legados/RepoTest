# Quickstart: Validating Final Processing

1. Approve all levels → request appears in the Final Processing queue; Creator and administrators notified.
2. Open as administrator: approved data, attachments, history visible.
3. Add final files; Creator files are listed separately; 21st final file rejected.
4. Correct a cost line → Data Correction Record exists; approvals not repeated.
5. Two administrators edit the same field → the stale one is blocked with a message.
6. Complete without confirmation → blocked; with confirmation (no final files) → Completed with who and when.
7. Try editing the request, final files or history after completion as any role → denied.
8. Creator and authorized users open the Completed request and see the final package.
9. Non-administrator cannot add final files or complete.
