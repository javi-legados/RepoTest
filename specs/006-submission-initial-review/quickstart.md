# Quickstart: Validating Submission and Initial Review

1. Submit a complete Draft → status Pending Initial Review; submitter and date recorded; Creator cannot edit.
2. Submit an incomplete Draft → every problem listed.
3. Click submit twice → one submission.
4. Deactivate all administrators and submit → blocked, stays Draft.
5. With two administrators, one releases; the other's attempt is rejected.
6. Return without comments → blocked; with comments → Creator can edit and resubmit; new Initial Review is created.
7. Release with no active first approver → blocked, administrators told which one is missing; fix and retry.
8. As administrator review your own request → allowed.
9. Check notification requests exist for submission and release.
