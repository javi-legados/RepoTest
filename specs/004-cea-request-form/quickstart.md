# Quickstart: Validating the CEA Request Form

1. Create a request; Project Manager, Location, Department and Date are filled and read-only.
2. Save with sections 1–2 only → Draft saved; reopen keeps data.
3. Toggle Supplemental Yes/No; check the visible and required fields; hidden values cleared.
4. Pick each category; metrics appear only for the four categories.
5. Add cost lines in all groups; subtotals and Grand Total update; negative cost rejected; Others pre-filled.
6. Add forecast lines: duplicate year/month blocked; month outside schedule warns.
7. Submit with 90% → blocked with difference; with 100% → passes this check.
8. Submit with Grand Total 0 or empty Detailed Description → blocked.
9. Project in Plan = Yes with Budgeted < Grand Total → warning, submission allowed.
10. Change currency; amounts unchanged.
