# Quickstart: Validating Rejection and Revision Review

1. Reject a request at any level → Creator sees comments, approver and date; request editable.
2. Edit form and attachments, add a correction note, resubmit → Pending Revision Review; locked.
3. Resubmit with no active administrator → blocked.
4. Administrator returns without comments → blocked; with comments → back to Creator.
5. Administrator releases → chain restarts at first applicable level; approvers are the current ones.
6. Remove the first approver then release → blocked, administrators notified.
7. Run three cycles → all recorded in order with comments and notes.
8. Deactivate the Creator while returned → On Hold, administrators notified; reassign the Creator.
9. Wait N days → one reminder to the Creator; request not closed.
